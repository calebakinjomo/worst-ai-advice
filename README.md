## How it works

`main.py` (Python 3, standard library only) writes the entry text directly to `$MAKEFUN_OUTPUT_DIR/entry.txt`, with no trailing newline.

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
